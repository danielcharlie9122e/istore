# iStore - Dummy Catalog Website

Ini adalah template website katalog *single-page* statis yang dibangun untuk mendemonstrasikan UI sederhana menggunakan Tailwind CSS. Data yang ada di dalam repositori ini adalah data dummy (fiktif).

## Teknologi yang Digunakan
- HTML5
- Tailwind CSS (via CDN)

## Cara Menjalankan
Karena tidak memerlukan *build process*, Anda cukup membuka file `index.html` langsung di browser Anda, atau menggunakan ekstensi **Live Server** di VS Code.
